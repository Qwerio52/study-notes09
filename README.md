# study-notes09

#### \# 第10章 网络爬虫和信息提取

\## 一、知识点总结

\### 1. 爬虫基础

\- 爬虫定义：按照预设规则自动从网页获取信息的程序

\- 爬虫标准流程：发起网络请求 → 获取HTML源码 → 解析网页提取数据 → 格式化输出数据

\- 爬虫规范：遵守 `robots.txt` 协议，控制访问频率，\*\*合法合规爬取\*\*，禁止恶意高频访问

\- HTML：网页标记语言，由嵌套标签组成，是BeautifulSoup的解析源



\### 2. Requests库（网络请求）

\- 功能：发送HTTP请求，获取网页响应内容

\- 核心方法：`requests.get(url)` 发起GET请求

\- 响应对象常用属性

&#x20; - `.status\_code`：状态码，200代表请求成功

&#x20; - `.text`：网页HTML文本

&#x20; - `.encoding`：设置编码，解决中文乱码

\- 常用参数：`headers`（模拟浏览器，绕过简单反爬）、`timeout`（超时限制）

\- 常见异常：403访问拒绝、请求超时、中文乱码



\### 3. Beautiful Soup库（HTML解析）

\- 功能：解析HTML，生成标签树，方便检索提取数据

\- 创建对象：`soup = BeautifulSoup(html, "html.parser")`

\- 核心API

&#x20; - `find(tag, attrs)`：查找\*\*第一个\*\*匹配标签

&#x20; - `find\_all(tag, attrs)`：查找\*\*所有\*\*匹配标签，返回列表

&#x20; - `.string`：获取标签内部文本

&#x20; - `.get("属性名")`：获取标签属性，例如 `href`

\- 注意：网页标签结构改动，爬虫代码会失效



\### 4. PrettyTable库（表格格式化）

\- 功能：将提取的数据整理成规整表格，控制台美化输出

\- 基础流程：创建表格对象 → 设置表头 `field\_names` → `add\_row()` 添加一行数据 → 打印输出

\- 适用场景：排名类、列表类数据展示（大学排名实例）



\### 5. 实例要点

\- 实例17 关键词搜索爬虫：拼接关键词到URL，请求页面，筛选匹配关键词内容

\- 实例18 中国大学排名爬虫：批量循环提取多条数据，最后用PrettyTable输出表格



\## 二、通用解题思路（爬虫编写步骤）

1\. \*\*需求分析\*\*：确定目标URL、需要抓取的数据项

2\. \*\*页面分析\*\*：F12打开开发者工具，定位数据所在标签、class/id属性

3\. \*\*发起请求\*\*：`requests.get()`，添加headers，校验状态码，处理编码

4\. \*\*解析提取\*\*：BeautifulSoup加载源码，`find` / `find\_all` 定位标签，循环读取数据

5\. \*\*数据整理\*\*：存储数据，使用PrettyTable格式化输出

6\. \*\*异常优化\*\*：增加超时判断、异常捕获，控制访问间隔



\## 三、学习心得

本章学习了Python爬虫整套基础流程，掌握了Requests、BeautifulSoup、PrettyTable三个库的搭配使用。Requests负责拿到网页源码，BeautifulSoup用来解析和筛选信息，PrettyTable优化最终展示效果。

通过两个实例，我完整走通了从网页请求到数据表格输出的流程，同时认识到爬虫高度依赖网页结构，网站改版会直接导致爬虫失效。

最重要的是建立爬虫合规意识，爬虫只是信息采集工具，使用时必须遵守网站规则，不能恶意爬取。后续会多加练习元素定位，增强代码健壮性。
